# LRH

Espanso prompt package backporting Logical Robotics Harness (LRH)
slash-command skills into short, paste-able `:lrh-` triggers, for sessions
that don't have the LRH skills installed or don't support Claude Code slash
commands directly.

This package is maintained in [Taurcode](https://github.com/xenotaur/Taurcode)
alongside the personal `taurcode` package, but ships and installs
independently — see `prompts/lrh/` in that repository for the canonical
source and
[the governing design proposal](https://github.com/xenotaur/Taurcode/blob/main/project/design/proposals/proposed/lrh-backport-and-hardening/00_proposal.md)
for why.
